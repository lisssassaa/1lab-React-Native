# Приложение на React Native с картой – Практическое задание
В этом задании вам предстоит создать мобильное приложение с использованием React Native и Expo, которое позволит пользователям взаимодействовать с картами и управлять изображениями, привязанными к местам на карте. Этот проект познакомит вас с основами мобильной разработки, компонентами React Native и TypeScript.

# Инструкции по установке

1. Клонируйте репозиторий:
```
   git clone ...
   cd ...
```
Или скачайте ZIP архив:
- Зайдите на GitHub репозиторий
- Нажмите "Code" → "Download ZIP"
- Распакуйте архив
2. Установите зависимости:
```
   npm install --legacy-peer-deps

```
   
3. Запустите проект через Expo:
```
 npm expo start
```
   
4. Откройте приложение в Expo Go на вашем устройстве.
Отсканируйте QR-код в терминале:
- Android: Откройте Expo Go → "Scan QR Code"
- iOS: Отсканируйте камерой, откроется Expo Go

# Структура проекта
app/ _layout.tsx - Настройка навигации

app/ index.tsx - Главный экран

app/ marker/ [id].tsx - Детали маркера

components/ Map.tsx - Компонент карты

components/ MarkerList.tsx - Список маркеров

components/ ImageList.tsx - Галерея изображений

types.ts - TypeScript типы

package.json - Зависимости

tsconfig.json - Настройки TypeScript


# Краткое описание принятых решений при реализации

- Использована библиотека react-native-maps для отображения интерактивной карты.
- Для передачи данных между экранами используется MarkerContext

# Известные проблемы и ограничения

- Нет поддержки постоянного хранения маркеров — данные теряются при перезапуске приложения.
- На некоторых версиях Android может потребоваться запрос дополнительных разрешений.
